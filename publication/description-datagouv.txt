Titre : Obs’COP 2025 — Explorer les opinions sur le climat

Description courte :
Explorez les opinions sur le changement climatique dans 30 pays grâce à une application interactive fondée sur l’enquête Obs’COP 2025. Cartes, classements, comparaisons, profils de population et relations entre indicateurs permettent d’analyser les préoccupations, les perceptions et les comportements. Les résultats sont filtrables et exportables, avec leurs sources, leurs bases et leurs limites méthodologiques.

Source : Obs’COP – EDF / IPSOS – Septembre 2025.

Mots-clés suggérés : climat, opinion publique, changement climatique, enquête, comparaison internationale, visualisation, Shiny
